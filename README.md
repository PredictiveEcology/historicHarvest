# historicHarvest

A SpaDES module that replays the forest harvest that actually happened (Canada Landsat
Disturbance, CanLaD, 1985 onwards) in a LandR (`Biomass_core`) simulation, and replants each
cut pixel with the species SCANFI shows growing there afterwards.

See `historicHarvest.Rmd` for what the module does, the `Biomass_genericDisturbance`
settings that use it, and the parameters.
